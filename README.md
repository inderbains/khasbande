# Khaas Bande International Airport

React + Vite project with animated planes:

- GILL
- BAINS
- GHUMAN

## Audio features

- Engine spool-up when a plane starts moving
- Jet/takeoff sound as it becomes airborne
- Optional background music
- Plane Sound On/Off button
- Music On/Off button

All sounds are generated in the browser with the Web Audio API, so there are no separate MP3 files to upload.

## Run locally

```bash
npm install
npm run dev
```

## Build for Hostinger

```bash
npm run build
```

Upload everything from the generated `dist` folder into Hostinger `public_html`.
