# Khaas Bande International Airport

React + Vite project with three animated planes:

- GILL
- BAINS
- GHUMAN

Click each plane to make it take off.

## Run locally

```bash
npm install
npm run dev
```

## Build for Hostinger

```bash
npm run build
```

Upload everything inside the generated `dist` folder into Hostinger `public_html`.

## GitHub

Upload the full project folder to a GitHub repository.
